# App Web-PFC-BIOPET
Este sistema web está diseñado para resolver la fragmentación de datos y los procesos manuales en clínicas veterinarias de pequeña y mediana escala en Ecuador. Al centralizar la información en la nube, elimina la dependencia de instalaciones locales y permite el acceso en tiempo real a historias clínicas, integrando dispositivos IoT e Inteligencia Artificial. El sistema gestiona tres roles clave (Veterinario, Administrador y Dueño de Mascota), se enfoca en la gestión administrativa, la historia clínica digital y el módulo de facturación.
